AnarchyClient is a Fabric mod. You add it to a Fabric installation of Minecraft Java Edition like any other mod.

<Callout type="warn">
  AnarchyClient is a side project by the 6b6t team, not an official product. It has no support
  guarantee. Use it at your own risk, and follow the rules of every server you join.
</Callout>

## What you need

- Minecraft Java Edition. Check the [downloads page](/releases/) for the Minecraft version of the current release.
- [Fabric Loader](https://fabricmc.net/use/installer/) 0.20.1 or later for that Minecraft version.
- [Fabric API](https://modrinth.com/mod/fabric-api) for the same Minecraft version.
- Java 25 or later. The official Minecraft launcher includes a matching Java runtime.

## Install the mod

1. Run the Fabric installer and select the Minecraft version of the release.
2. Download the AnarchyClient JAR from the [downloads page](/releases/).
3. Put the JAR and Fabric API in the `mods` folder of your Minecraft directory. Create the folder if it does not exist.
4. Start Minecraft with the Fabric profile.

If you use Prism Launcher, Modrinth App, or another launcher, create a Fabric instance for the release's Minecraft version. Then add both JARs to the instance's mods folder.

## Open the menu

Join a world or a server, then press <kbd>Right Shift</kbd>. To change the key, open **Options**, **Controls**, **Key Binds**, and find **Open AnarchyClient** under **Miscellaneous**.

The menu opens over the game, which stays visible behind the panels.

- The dock on the left lists the module categories. Below them are the Friends, Profiles, and Theme tabs.
- The module panel shows the modules of the selected category. Type in the search field to search every category.
- Select a module to open its settings. The switch in the settings panel turns the module on or off.
- Set a keybind in a module's settings to toggle it without opening the menu.

The [module list](/modules/) describes every module.

## Your settings

AnarchyClient saves module states, settings, keybinds, and friends in `config/anarchyclient.json` in your Minecraft directory. Saved profiles go to `config/anarchyclient/profiles.json`. Copy these files to keep a backup or to move your setup to another installation.

## If something does not work

- Make sure the Minecraft version, Fabric Loader, and Fabric API match the release.
- Remove other utility clients from the mods folder. Two clients can change the same game behavior and conflict.
- Check `logs/latest.log` in your Minecraft directory for errors that name AnarchyClient.

To report a bug, [open an issue on GitHub](https://github.com/6b6t/AnarchyClient/issues). Give the AnarchyClient version, the Minecraft version, your other mods, and the error from the log.
